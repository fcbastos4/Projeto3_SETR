SPI MISO lines

Some controllers support dual, quad or octal MISO lines connected to slaves. Default is single, which is the case most of the time. Without @kconfig{CONFIG_SPI_EXTENDED_MODES} being enabled, single is the only supported one.

#define SPI_LINES_SINGLE   (0U << 16)
 
#define SPI_LINES_DUAL   (1U << 16)
 
#define SPI_LINES_QUAD   (2U << 16)
 
#define SPI_LINES_OCTAL   (3U << 16)
 
#define SPI_LINES_MASK   (0x3U << 16)
