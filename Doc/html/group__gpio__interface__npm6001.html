nPM6001-specific GPIO Flags

The drive flags are encoded in the 8 upper bits of gpio_dt_flags_t as follows:

  • Bit 8: Drive strength (0=NORMAL, 1=HIGH)
  • Bit 9: Input type (0=SCHMITT, 1=CMOS)
