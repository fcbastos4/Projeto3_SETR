Descrição detalhada

Este módulo é responsável por declarar funções relacionadas ao controlo do sistema.

Este módulo lida com a inicialização e o controlo dos periféricos de saída, como GPIOs e PWM, usados para ativar ou desativar elementos de controlo como aquecedores com base nos valores de temperatura definidos na aplicação.
