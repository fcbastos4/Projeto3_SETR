Request a GPIO pin to be configured to a specific function. GPIO0..4 of AXP192 feature various functions (see axp192_gpio_func for details). A GPIO can only be used by one driver instance. Subsequential calls on the same GPIO will overwrite according function.

Parâmetros
devaxp192 mfd device
client_devclient device the gpio is used in
gpioGPIO to be configured (0..4)
funcFunction to be configured (see axp192_gpio_func for details)
Valores retornados
0on success
-EINVALif an invalid GPIO number is passed
-ENOTSUPif the requested function is not supported by the given
-errnoin case of any bus error
