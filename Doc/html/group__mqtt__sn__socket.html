Descrição detalhada

MQTT-SN Client Implementation.

MQTT-SN Client's Application interface is defined in this header. Targets protocol version 1.2.

◆ mqtt_sn_topic_type

enum mqtt_sn_topic_type

MQTT-SN topic types.

Valores de enumerações
MQTT_SN_TOPIC_TYPE_NORMAL 

Normal topic. It allows usage of any valid UTF-8 string as a topic name.

MQTT_SN_TOPIC_TYPE_PREDEF 

Pre-defined topic. It allows usage of a two-byte identifier representing a topic name for which the corresponding topic name is known in advance by both the client and the gateway/server.

MQTT_SN_TOPIC_TYPE_SHORT 

Short topic. It allows usage of a two-byte string as a topic name.
