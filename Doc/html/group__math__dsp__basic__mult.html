 Floating-point vector multiplication.
 

Descrição detalhada

Element-by-element multiplication of two vectors. 

    dst[n] = src_a[n] * src_b[n],   0 <= n < block_size.

There are separate functions for floating-point, Q7, Q15, and Q31 data types.
