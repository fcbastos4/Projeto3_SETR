◆ Z_STACK_PTR_TO_FRAME

#define Z_STACK_PTR_TO_FRAME (   type,
  ptr 
)     (type *)((ptr) - sizeof(type))

Helper macro for getting a stack frame struct.

It is very common for architectures to define a struct which contains all the data members that are pre-populated in arch_new_thread().

Given a type and an initial stack pointer, return a properly cast pointer to the frame struct.

Parâmetros
typeType of the initial stack frame struct
ptrInitial aligned stack pointer value
Retorna
Pointer to stack frame struct within the stack buffer
